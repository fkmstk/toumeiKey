# TypingOverlay

YouTube などの動画を見ながらタッチタイピングを練習できる、半透明・最前面表示の macOS アプリ。

## ビルドと起動

```bash
./build.sh && open TypingOverlay.app
```

起動中のアプリは build.sh が自動で終了してから作り直す。

## 使い方

- 帯をクリックするか **⌃⌥T** でタイピング開始。もう一度 ⌃⌥T でブラウザ側に戻る（動画は再生されたまま）
- ブラウザの全画面表示の上にも重ねて表示できる
- 背景をドラッグで移動、端をドラッグでサイズ変更
- 右クリックでメニュー（モード・出題・タイプ音・コンパクト表示など）
- タイピングしていない間は帯が薄くなって動画が見やすくなる（マウスを乗せると戻る）
- 帯の高さは内容に合わせて自動で伸び縮みする
- マウスを乗せると右上にモード切替（日本語 / English / カスタム）と設定ボタンが出る
- メニューバーの ⌨ アイコンから表示・終了など

| キー | 動作 |
| --- | --- |
| ⌃⌥T | タイピング ⇄ ブラウザのフォーカス切替（どのアプリからでも） |
| Esc | 行の最初からやり直す |
| Tab | 行をスキップ |
| ⌘1 / ⌘2 / ⌘3 | 日本語 / English / カスタム |
| ⌘, | 設定 |
| ⌘S | 統計・分析 |
| ⌘K | コンパクト表示 |
| ⌘V | クリップボードの文章で練習 |
| ⌘O | テキストファイルで練習 |
| ⌘W | 隠す |
| ⌘Q | 終了 |

## 機能

- **問題**: 日本語の文章150・単語183、英語の文章101・単語285。設定または右クリックの「出題」で 文章 / 単語 / ミックス を切り替え（単語ドリルは毎回ランダムに組み合わせる）

- **日本語ローマ字入力**: shi/si、chi/ti、kya/kixya、っ（子音重ね / xtu）、ん（n 1回でも可）など複数の打ち方に対応
- **キーボードガイド**: 次に押すキーと使う指を色で表示。JIS / US 配列を自動判別（設定で固定も可）
- **英数入力へ自動切替**: タイピング欄にフォーカスすると英数入力に切り替わり、離れると元に戻る
- **統計・分析ウィンドウ**（⌘S / 帯のグラフボタン / 右クリック）: 期間（7日・30日・全期間）ごとの平均 KPM・正確率・練習時間と前の期間との比較、連続練習日数、KPM の推移（各行と10行移動平均）、日別の練習時間・KPM・正確率、キーボードのヒートマップ（ミス率 / 打鍵間隔）、指ごとのミス率、苦手なキー・遅いキー・よくある打ち間違い・苦手なかなのランキング、最近の行。グラフはマウスを乗せると詳細が出る。CSV 書き出しにも対応。記録は ~/Library/Application Support/TypingOverlay/analytics.json に保存
- **帯の統計**: KPM・正確率・ミス・前の行の KPM・ベスト KPM・苦手キー。KPM は打鍵中の時間だけで計算するので、動画に見入って手が止まっても下がらない
- **フォント**: モダン（ヒラギノ角ゴ + JetBrains Mono）/ まるっと（ヒラギノ丸ゴ）/ 教科書（クレー）/ システム
- **タイピング音**: コトコト（木）/ カチカチ（青軸風）/ スコスコ（静音）/ タイプライター / ポップ。打つたびに音程が少し揺れ、左手のキーは左から・右手のキーは右から聞こえる。スペースは低め。ミス音と行クリアのチャイムは個別にオン・オフできる
- 背景・全体の透明度、文字サイズ、今日の打鍵数の記録

## カスタム文

1行に1問。漢字を含む文は `|` の後に読みをひらがな（カタカナ可）で書く。

```text
今日は晴れ|きょうははれ
the quick brown fox
ひらがなだけの文はそのままでOK
```
